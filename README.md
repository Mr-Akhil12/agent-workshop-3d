# The Agent's Workshop

Interactive 3D portfolio scene built with Three.js and Vite.

A neon cyberpunk garage featuring a glossy black Toyota Runx (metallic flake), a Streamlit-style laptop dashboard, a flame easter egg, and orbit/pointer controls. Deployed as a static site on Vercel.

## Live

https://agent-workshop-3d.vercel.app

## Stack

- Three.js (WebGL scene, lighting, materials)
- Vite
- Vanilla JS modules

## Development

```bash
npm install
npm run dev
```

Or serve the built assets:

```bash
npm run build
npx serve dist
```

## Notes

Assets live under `assets/` and `data/`. This is a visual showcase, not a backend app — no API keys required.
